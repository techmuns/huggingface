Methodology

  • Data source: Hugging Face Hub API, scraped weekly via cursor walk.
  • Spaces are deduplicated by normalized title + linked model set. Template clones are clustered; only one representative per cluster is counted.
  • ~53% of new Spaces are sdk: static. Included in all counts.
  • Classification: deterministic rules (tags, linked models, slug, README prose) first; remaining Spaces classified by Claude Haiku 4.5 via Bedrock.
  • Technology tags are AI techniques (RAG, agentic, multimodal, quantized, MoE…), not frameworks. The build SDK is reported separately above.
  • Growth windows compare each trailing window against the immediately preceding window of equal length — 4W compares weeks W-3–W against W-7–W-4, not this week against one week three months ago.
  • Primary use case is single-valued (sums to 100%). Verticals, technologies, and model families are multi-label (penetration rates, do NOT sum to 100%).
  • Downloads are a rolling 30-day figure (a rate, not a total). Likes are cumulative.
  • Small-denominator cuts (<10) are suppressed rather than reported as wild percentages.
